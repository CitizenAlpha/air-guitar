# Air Guitar

Draw strings of light with your fingers and play them, using your phone's front camera.

- Pinch and drag to stretch a string (or pinch with both hands and pull apart).
- Flick your index finger through a string to play it. Longer strings play lower notes.
- Touch mode works without the camera.

Single static page: MediaPipe hand tracking runs in the browser, sound is synthesised with Web Audio. No build step, no server.
Live via GitHub Pages: Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
